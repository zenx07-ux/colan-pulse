# ColanPulse

Workforce observability dashboard rebuilt with the [Elastic UI Framework](https://eui.elastic.co/).

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`). The app lands on **Employees Activity**, matching the original screen, now implemented with EUI layout, navigation, filters, and tables.

## Stack

- React 18 (EUI does not support React 19)
- [Elastic UI](https://eui.elastic.co/docs/getting-started/setup/) with the Borealis theme
- Vite
